1. Editar dados

Digite ou altere diretamente o nome da série, o volume adicionado e o pH medido. O gráfico acompanha as alterações.

Use vírgula ou ponto decimal. O pH válido vai de 0 a 14; o volume deve ser maior ou igual a zero. Linhas incompletas não são plotadas. A entrada e a análise aceitam casas decimais de milésimos (0,001).

Preencha volume e pH para inserir pontos no gráfico.

2. Visualizar gráfico

Os eixos são calculados a partir dos dados válidos. Nenhuma curva é prevista ou gerada por um modelo químico.

Formato para importar dados de uma planilha

Use um arquivo CSV separado por ponto e vírgula, com cabeçalho. A coluna Série é opcional; o volume e o pH são necessários. Também é possível usar duas colunas (Volume e pH).
